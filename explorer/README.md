# RuGraph Explorer

Live tutorial: https://ruvnet.github.io/ruGraph/

A browser-local tutorial and explorer for the real Rust WASM runtime. Six lessons explain dependency traversal, contradictory observations, expiry, grants, exact cosine retrieval and counterfactual sensitivity.

Edit a program or its JSON inputs, select graph nodes, inspect evidence, replay receipts and export a receipt. The orbital canvas, curved signal paths, scanning beam and rotating node rings follow the RuVector Explorer palette. Phones use a portrait graph, 44 px touch targets, a lesson picker and a persistent Run dock. Motion can be paused and respects system reduced motion preferences. Animation illustrates dependency links; only actual runtime decisions color evidence status.

## Build and run

Use the pinned Rust 1.90.0 toolchain, wasm32-unknown-unknown target and wasm-bindgen 0.2.105 from the root contributing guide.

```bash
bash scripts/build-explorer.sh
python3 -m http.server 8000 --directory explorer/dist
```

Open http://localhost:8000. Module Workers require HTTP or HTTPS.

## Validate

The lesson tests use the Node WASM package generated by `bash scripts/test-graph-language-wasm.sh`. Chrome is required for the browser acceptance test.

```bash
node --test explorer/test/lessons.test.mjs
python3 scripts/test-explorer-browser.py
```

GitHub Actions builds the pinned runtime, runs both suites and deploys the exact tested directory to Pages on main. `build.json` identifies the source revision and asset hashes. Revert the source commit to roll back and redeploy.

Inputs live only in browser memory. The page limits each editor to 1 MiB, bounds rendered elements, and terminates operations after 8 seconds in a Worker. Receipt export is explicit. Host latency includes message transfer and compilation. Hashes verify integrity rather than producer identity. See ADR-GL-013 for the trust boundary and acceptance contract.

The evidence focus card explains the selected node using the actual runtime decision, highlights its connected paths, and links to the witness inspector. Nodes outside a completed query are explicitly labeled. Session-only lesson progress and a next-lesson action guide exploration without storing user inputs. The mobile Code action always opens the source editor.

## Project workspace

Open and save version 1 `rugraph.project` JSON files. Source, snapshot and context remain raw strings so duplicate keys and u64 values reach the strict Rust parser unchanged. Import is limited to 8 MiB with 1 MiB per editor. Opening a project clears active results and does not execute code. Saving explicitly downloads input data, which can contain sensitive observations.

Compile exposes the actual WASM compiler output. The session retains two successful runs with exact input text and receipts, shows decision and witness lineage differences, and supports restoring or saving either input set. This history is in memory only and does not authenticate sources. Import a saved run and execute it to reproduce its receipt. Results from inputs edited during execution are discarded.

Mobile programming provides paired delimiters, indentation and an expandable editor. No new external dependencies or storage services are required.

The welcome tour introduces graphs, evidence and programming through three animated SVG scenes. It opens on page load, can be skipped or reopened with Quick tour, respects reduced motion, and includes a separate pause button. It stores no preference or user data and never runs a program automatically.
